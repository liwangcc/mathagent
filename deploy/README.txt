MathAgent 部署入口已统一为仓库根目录的 `deploy.sh`。

## 推荐流程

```bash
# 仓库根目录
bash deploy.sh --dry-run
# 检查发布包、测试结果和目标环境后，再在获授权窗口执行
bash deploy.sh
```

`--dry-run` 用于测试、构建、差异检查和发布包审计；正式脚本负责受控打包、备份、服务更新及健康检查。具体 systemd、Nginx、Gunicorn、Redis 和资源配置位于本目录的脚本/模板中，以脚本当前内容为准。

## 安全边界

- 不使用密码登录或把密钥写入命令、仓库、日志和文档；生产凭据只放受保护环境。
- 不把后端端口直接暴露公网；公网入口应由受控反向代理提供 HTTPS。
- 发布包不得包含 `.env`、数据库、上传/输出目录、虚拟环境或学生数据。
- 生产配置、数据库迁移、服务重启和回滚须明确授权，并保留可验证回执。

## 排查顺序

1. 查看发布脚本输出和 `git status --short`。
2. 检查服务状态、`/api/health`、数据库状态和 Redis 协调状态。
3. 再检查模型线路、限流和业务请求；健康检查通过不等于批阅链路通过。

旧版“手工创建服务器、开放 8080、密码 SSH、复制粘贴 setup.sh”的说明已废弃，不要照做。
