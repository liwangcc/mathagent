## 样本来源（重要）

本目录**不含任何真实学生数据**：试卷与答题卡是教师为验证流程自行打印的，手写作答由教师本人书写，卷头学校名取自打印模板标题（已遮盖）。因此结论描述的是**真实的手写形态与真实的生产链路**，而不是真实学生的作答分布。

## 脱敏规则

- **图片 · 卷头**：印刷的「学校名 + 考试名称」整行用白色块覆盖（不是只盖左侧，标题是横贯居中的）
- **图片 · 密封线**：竖排手写的姓名/考号整条覆盖
- **图片 · 差分图**：模板差分会把学生笔迹保留下来，**手写姓名也在其中**，因此差分图左侧密封线条带单独遮盖
- **图片 · 边界**：所有覆盖区域都不含答题笔迹，逐张用视觉复核（姓名/校名已不可读、Q 题号完整、答案未被切）
- **文件名**：学生真实姓名不进入文件名，统一用 `S01` / `S02` / `S03` 编号（`S01` 差分案例、`S02` 手写案例、`S03` 全错案例）
- **回执**：模型原始输出原样保留 —— 数据可以难看，但不能是改过的。**唯一例外**：模型自己把「姓名：」转录进文本的，姓名已替换为编号（已在对应 README 注明）
- **03 的回执**：整套试卷的转录文本随回执公开，已按同一规则扫描——手机号、校名、考号、准考证号 0 命中。上一轮 40 条里曾有 2 次模型把密封线里竖排的手写姓氏转录出来，图片侧据此把遮盖向下延长到笔迹位置（原遮盖条下边缘比笔迹高约 200 px）；本批 200 条回执用新图重跑，姓名 0 命中

## 边界

这些数据只说明**当时那份样本、那组参数**下的结果：

- 样本量小（1–2 份卷），不能当作跨学校、跨题型、跨设备的准确率承诺
- 25 题样本只有选择与填空短答案，没有大题长公式
- 判分项共 42 项，`wrong = 0` 只代表这批转写没有触发误判，不代表任何输入都不会误判
- **「模型把学生答案往标准答案上改」已实测到**：原图（含印刷题干与选项）下 Q21 有 6/10 次把学生写的 `4√5` 读成 `4√5/5`（标准答案 `4/5`），差分图 0/10。生产提示词本就禁止据题干猜答案，仍然发生——提示词只决定概率；本样本里只有去掉题干（差分）做到了 0（单卷单题，0/50 的 95% 置信上限约 5.8%，不等于发生率为 0）
- 全错卷 75 次转录中与标准答案一致的次数 0/75：该卷错答案离标准答案太远、没有漂移空间，只说明极端错答不会被抬分，不代表**近错答案**安全
