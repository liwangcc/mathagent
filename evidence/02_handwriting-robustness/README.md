# 02 · 手写转录的鲁棒性：漏字符不影响判分

> **样本来源**：答题卡为教师自行打印的模拟卷，手写作答由教师本人书写；模型转录出的「姓名：」字段为测试用名，发布版已替换为编号 `S02`。不含任何真实学生数据。

## 这份数据想回答什么

手写**不是**印刷体，也不会每个字符都清楚。问题是：

1. 模型能不能把这样的手写转录出来？
2. 转录过程中**丢了几个不影响逻辑的符号**（⊥、⊂、连接符、括号风格），送到判分环节还判得对吗？

## 素材

- 一张高中数学答题卡（S02，教师自印模拟卷），含 12 道选择、4 道填空、第 17–19 三道大题
- 按教师确认的分栏切成 3 栏（裁剪参数与核验图见原实验记录）
- 人工真值：`truth.md`（选择 AACADDBAADCC、填空 743 / 1 / 2 / 4π、第 17–19 题逐问）

## 方法

**转录**：3 栏图一次请求送 `qwen3.8-flash`（关闭思考），得到整卡转录文本（`ocr/` 下 6 份原始回执）。

**判分**：把每路转录直接喂**生产判分链** `services/flash_grading.judge_text_paper`
（`GRADING_PROVIDER=qwen3.8-flash`，详细模式，`enable_thinking=true + reasoning_effort=high`，
即生产批改合同原样，未做任何覆盖），对第 17/18/19 题 + 填空 13–16 共 7 项逐项判定。

## 哪些缺陷被宽容度吸收

被判 correct 的实际转写缺陷：

- `⊥` 丢失（F1v1 一路丢了 4 处，仍全部判对）
- `⊂` 丢失、连接符丢失
- `CD → CO` 混淆
- `ξ` 丢失（"40x元"）
- `∠` 丢失、标签 `(2) → (1)`
- 排版差异（同一行被拆成两行）

依据 = 现行判分规则"禁止因书写格式、符号风格、解题路径不同判错；数学等价必判 correct"，
判分模型会按上下文重建被漏掉的符号。

## 哪些**没有**被吸收（这条同样重要）

5 处 partial 全部来自**关键步骤的符号/数字级错读**，不是"漏字符"：

- `(2|BM|)²` 被读成 `(½|BN|)²` 或 `(2|AM|)²`
- `40xξ` 被读成 `40x×2/3`
- 坐标 `2` 被读成 `1`，导致后续法向量级联错误

结论：**"漏一个不参与计算的小符号"能被吸收；"把参与推导的关键符号读错"不会被吸收，会判 partial。**
这个边界是产品对教师承诺的底线。

> 边界：本卡的判分真值中，第 17 题第 (2) 问来自模型转录经用户裁定，第 18/19 题真值来自计算解而非纯视觉识别；
> 选择/填空与第 17(1) 为用户逐题人工核对。详见 `truth.md`。
