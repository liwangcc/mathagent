# 离线 3D 运行库

课件内嵌 Three.js `r160`（MIT License），来源：
https://github.com/mrdoob/three.js/releases/tag/r160

`three.min.js` 会被服务端生成器直接内嵌进每个 HTML，因此双击课件时不需要网络或 Node.js。

## JSXGraph
内嵌 JSXGraph 1.10.1（MIT 许可）用于二维坐标图课件；来源：https://github.com/jsxgraph/jsxgraph。
jsxgraphcore.js 与 jsxgraph.css 会被生成器内嵌，双击课件无需网络。
