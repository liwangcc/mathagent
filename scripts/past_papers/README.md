# 整卷真题离线流水线

Offline tooling that turns collected Gaokao math sources into the teacher-facing
library served by `routers/past_papers.py`. Contract and gates live in the
internal design note 2026-10-08《整卷真题库》, which is not published with this
repository.

The web app never runs these scripts. They need a separate tooling venv with
`pymupdf` and `playwright` (printing uses the installed Microsoft Edge via
`channel="msedge"`, so no browser download is needed). `build_library.py` and
`paper_format.py` are pure Python.

| Step | Command | Output |
| --- | --- | --- |
| 1. Inventory | `python -m scripts.past_papers.inventory --workspace WS --raw DIR [--raw DIR] [--sources-json F]` | `WS/originals/<sha256>.pdf` (read-only, content-addressed), `WS/inventory/{files,candidates,summary}.json` |
| 2. Transcribe | write `WS/papers/<id>/student.paper.txt` (format: `paper_format.py` docstring) from ≥2 independent source lineages; record them in `sources.json` | — |
| 3. Figures | `python -m scripts.past_papers.figures candidates --pdf SRC --out DIR`, then `... figures cut --pdf SRC --page N --rect x0 y0 x1 y1 --paper-dir WS/papers/<id> --id q11-fig --width-mm 40` | vector SVG crops + `figures.json` with source hash, page and crop rectangle |
| 4. Render | `python -m scripts.past_papers.render_paper --paper-dir WS/papers/<id> --katex-dir KATEX_DIST [--kind answer]` | `build/<kind>/<kind>.pdf`, previews, 150-dpi check pages, `render_report.json` (blocking issues) |
| 5. Cross-check | `python -m scripts.past_papers.crosscheck --paper-dir WS/papers/<id> --pdf SRC` | per-question CJK/digit/letter differences to adjudicate |
| 6. Verify + review | `verification.json` (verifier) and `review.json` (independent reviewer, bound to the transcription SHA-256) | — |
| 7. Build library | `python -m scripts.past_papers.build_library --workspace WS --out LIB --regions references/past_papers/region_usage.json [--rights DECISIONS]` | `LIB/catalog.json`, `LIB/files/...`, `LIB/previews/...`, `WS/coverage/coverage.{json,csv}` |

Rights decisions are operator-owned and never generated by the pipeline; without
one, every paper stays `unresolved` and is not shown to teachers.

On Windows/Git Bash write source files with an editor, not heredocs (backslashes
in TeX get mangled), and run Python with `PYTHONIOENCODING=utf-8`.
