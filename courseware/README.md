# MathAgent 课件库

离线课件按学段隔离，目录与前端下载副本一一对应：

- `小学/`：小学章节课件（P01–P17，含 3D 立体图形、条形图与平均数）
- `初中/`：初中章节课件
- `高中/`：高中章节课件

每个章节文件都按章节名命名。教师下载时先由账号学段过滤，再按章节选择；不要把不同学段的同名知识点合并。

所有图形、顶点、模型和视角移动都必须由教师长按后拖动触发，短点击不得改变位置；项目内不设置“移动模式”或“开始移动”按钮。

## v4 完整章节导入

本项目已纳入三份完整版 v4 的最终单文件 HTML：小学 P01–P17、初中 J01–J20、高中 H01–H21，共 58 章。原有的 13 个单点演示样例中，12 个已于 2026-09-14 删除（知识点全部包含在 v4 完整章节中，保留会与章节卡重复，历史文件可从 git 取回）；「高中/空间几何关系.html」（WebGL 真三维·线线/线面/面面关系，教师自制）**保留**，与 H09 章节两份并存。对应文件位于本目录三个学段下；`catalog_v4.json` 保存来源压缩包哈希、成品哈希和前端静态副本路径。课件库首次访问时会把这些已存在的成品登记为公共课件，预览和下载使用同一份 HTML。

压缩包内的 Linux Chromium 验证记录随来源保留，但其 `file://` 双击、真实 WebGL、实体触摸屏和 Windows/Edge 实机项目仍按未验证处理；本项目验收只报告实际运行过的检查。v4 成品的直接指针操作以各文件内的实际交互契约为准。
